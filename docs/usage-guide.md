# 使用指南

> 按当前实现重写（2026-11-25）。

## 一、启动与访问

```bash
start.cmd                 # Windows 双击/命令行（自动准备 Git Bash + Python）
start.ps1 --port 8080     # 便携模式，自定义端口
python main.py            # 已具备 Python 环境时直接启动
cli.cmd                   # 终端客户端（连接已运行的服务）
```

启动后浏览器打开 `http://localhost:{port}`。远程访问需在设置中配置 `access_token`
（推荐）或 `allowed_ips`。

## 二、工作区与会话

- **工作区**：一个目录 = 一个工作区（隔离会话/记忆/规则/产物）。可新建、改名、注销
  （注销只移除索引，保留目录与文件）。
- **会话**：按通道（网页/QQ/微信/邮件/终端/定时）归属；支持新建、重命名、隐藏、
  批量操作、导出/导入、删除与分享链接（只读页）。
- 会话内切换模型（输入框模型下拉）只影响当前会话。

## 三、对话与协作

- 直接输入消息；`Shift+Enter` 换行。
- 运行中再发送会**入队**（排队条可暂停/恢复/清空/删除单条）。
- 停止按钮：红色停止当前回合，黄色停止后台任务；`/stop` 同效。
- 推荐输入：输入框下方建议可点击填入；空会话有示例。
- 提问卡/审批卡在对话内渲染；审批卡支持「允许一次/允许并记住/拒绝/中止」，
  超时（默认 300s）自动结算，Web/CLI 可自动恢复。
- 文件交付：模型用 `send_user_file` 把工作区文件发给你（Web 显示下载卡片）。

## 四、会话内指令（Web/QQ/微信/CLI 通用）

| 指令 | 作用 |
|---|---|
| `/h`、`/help` | 帮助 |
| `/w [序号\|名称]` | 查看/切换工作区 |
| `/s [序号]` | 查看/切换会话 |
| `/new [名称]` | 在当前工作区新建会话 |
| `/mode [latest\|dedicated]` | 独立会话 / 接着最新会话 |
| `/status` | 工作区/会话/用量与剩余额度 |
| `/stop`、`/stop bg` | 停止当前回合 / 后台任务 |

Web 额外支持 `/goal`：`/goal <目标>` 设定长期目标并自动循环执行，
`/goal status|pause|resume|clear` 管理。

## 五、常用能力

### 文件与代码

- 文件树浏览/预览/编辑/上传；拖拽文件到窗口上传到 `uploads/`。
- 让 agent 读写/搜索代码，或运行命令（bash/pwsh）与 Python 脚本。
- 长输出外置到会话目录，可用 `read_tool_result` 分页读取。

### 教材

工作区设置 → 教材下载：选学段/学科/版本/年级，后台下载官方教材并生成 Markdown；
对话中可用 `textbook_find/outline/read/search/original` 检索与阅读。

### 记忆

工作区需在记忆管理页开启。开启后回合结束会后台提取记忆；可查看/编辑/归档条目、
手动整合。全局 cron 会定期整合所有已开启工作区。

### 定时任务

对话中让 agent 创建（如「每天早上 8 点汇总新闻」），或在工作区设置里管理；
支持 `at`/`interval`/`cron`、错过执行策略、投递回原会话或指定会话。

### 工作流

面板创建多步骤工作流：监督者按步骤派发 worker/lite 执行，产物与结果在
`{workspace}/workflows/{name}-{id}/{时间戳}_{run_id}/`；可只重跑某一步。

### 浏览器与联网

agent 可打开浏览器操作网页、截图、保存 PDF；`web_search` 走必应检索。
DeepSeek 模型在服务端支持联网工具时会自动启用。

### 课件答题

课件页面答题结果会回传（CORS 白名单），自动维护错题本与成绩页。

## 六、青少年模式

家长在全局设置开启并设密码；可设使用时段/每日时长、工作区白名单与各项策略。
硬禁动作（删除会话/撤销消息/删执行日志/注销工作区）解锁也不放行。

## 七、升级

「关于」页检查并应用升级；升级后自动重启（由启动脚本托管）。启动时会自动执行
数据迁移（配置备份在 `data/cili/backup/migrations/`）。

## 八、常见问题

- **无法访问**：检查端口（`data/cili/server.json`）、`access_token`、防火墙/反代。
  反代部署需在代理层封禁 `/api/fs/browse` 与 `/api/open-in-explorer`（本机端点）。
- **模型报错**：设置页「测试」定位；429 配额类通常需充值/换模型。
- **附件过大**：各接口有体积/条数上限（QQ/微信/邮件更严），超限会降级为文件卡片。
- **浏览器工具异常**：`browser(action="reset")` 会重启 Chrome 并重建连接。
