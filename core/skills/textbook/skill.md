# Textbook — 教材数据使用指南

数据来自国家中小学智慧教育平台收录教材的 AI 提炼版（章节化，保留原文措辞）。工具按需加载，**不要试图一次性读整本书**。

## 工具选择决策树

```
要「有哪些教材/哪本」            → textbook_find（可先无条件调用看概览）
已知书，要「有哪些章」           → textbook_outline（书级目录）
要「这一单元有哪些课文」         → textbook_outline(book=..., chapter=N)（章内篇目，自动过滤思考/练习类标题）
要「整本书的章节脉络」           → textbook_outline(book=..., chapter=all)（一次返回全部章的小节）
已知书和章，要「内容」           → textbook_read
不知道在哪本书，按知识点找        → textbook_search（跨书全文检索）
需要核对/引用教材原句            → textbook_original（仅本地有原文包时可用）
```

典型链：`find → outline → read`；检索直达：`search → read`。

## 使用要点

- **引用规范**：凡给出教材内容，必须标注「书名 · 版本 · 年级 · 册次 · 第N章 标题」；
- **不要编造教材原文**：出题、引用、背诵类任务先读原文再产出；
- **检索词建议 ≥3 个汉字**（2 字查询走较慢的扫描回退）；
- **读整章要分段**：textbook_read 默认每次 8000 字（避免超过 1 万字符被平台落盘），长章节先用 outline(chapter=...) 定位小节再分段读取；
- **年级筛选**：高中教材统一标「高中年级」，按 高一/高二/高三 筛选会自动兼容（高中语文/数学等按「必修上/下、选择性必修上/中/下」分册，没有「高二上册」这种册名）；
- **多版本对比**：同一学段/学科/年级用 `textbook_find` 列出各版本，再分别 read 对应章节；
- **数据边界**：仅含数据包内已提炼的教材（特殊教育暂未收录：盲校/聋校/培智教材及特教学段已排除，后续完善后补回）；体育与健康大部分版本、信息科技教学指南不在库中；教师用书不含；
- **数据未就绪时**（工具返回"正在同步"提示）：不要重试循环，告知用户稍后再试或先回答不依赖教材的问题。
