# 课件质检清单

## 一、结构（阻断）

- [ ] `schema_version` = `1.0`，`template` = `parchment-v1`
- [ ] `mode` 合法；错题模式有 `focus`
- [ ] 页面 ID、题目 ID 全局唯一
- [ ] 布局/块类型合法；`diagram` 布局有图示，`quiz` 布局有题目
- [ ] 单选/多选答案与选项匹配；填空答案数组长度与空格数一致
- [ ] 图片路径存在且在工作区内

## 二、资源（阻断）

- [ ] HTML 无 `http(s)://` 外部引用
- [ ] 无模板残留 `{{SLOT}}`
- [ ] 文件 ≤ 15MB（>10MB 警告）
- [ ] 不包含模型提供的原始 HTML/SVG/脚本

## 三、版式（阻断/警告）

- [ ] 每页内容不溢出、不重叠
- [ ] 每页至少一个视觉元素
- [ ] 纯文字页 ≤ 1 页（警告）
- [ ] 图片不变形，图示与图注一致
- [ ] 全篇字号、间距、页码、页脚一致
- [ ] 卡通手绘风格一致，无企业/办公风元素

## 四、内容（阻断/警告）

- [ ] 每页正文 ≤ 180 字，讲稿 ≤ 300 字
- [ ] 每页有教材出处，或标注「非教材内容」
- [ ] 无占位符残留（xxxx/lorem/待补充）
- [ ] 公式可渲染、图示参数合法
- [ ] 错题模式：类型统计与错题本一致；错例原文引用；变式题标注「变式」

## 五、体验（人工）

- [ ] Web 文件树点开 `.html` 能直接预览
- [ ] 桌面与手机无横向滚动
- [ ] `←/→` 翻页、`N` 讲稿、`F` 全屏可用
- [ ] 测验可作答、判分正确、解析显示
- [ ] 提交后显示「已记录」，`成绩记录.html` 已刷新，错题进入 `错题本.md`
- [ ] 离线打开无外部请求

## 六、自动质检命令

```text
python(action="execute_file",
       script_file="$SKILL_DIR/scripts/qa_courseware.py",
       args="--plan <plan> --html <html> --out .cili/tmp/courseware/<slug>")
```

查看：

- `.cili/tmp/courseware/<slug>/report.json`
- `.cili/tmp/courseware/<slug>/page-*.png`
- 用 `read_image` 抽查截图；有问题改 plan 后重渲染，最多 3 轮。
