# 布局与写作规则

## 页面节奏（章节课件，15 页以内）

1. `cover` 封面：标题、副标题、年级/教材。
2. `objectives` 学习目标：2–4 条，每条 ≤ 20 字。
3. `section`（可选）：大章节分隔。
4. `concept` 概念：引导句 + 公式/重点框 + 可选图示。
5. `diagram` / `two-column`：图解或图文对照。
6. `steps`：例题/方法步骤，3–5 步。
7. `quiz`：2–5 题，覆盖本页知识点。
8. `summary`：3 条以内要点 + 一句复习建议。

## 每页规则

- 标题 ≤ 20 字；正文 ≤ 180 字；讲稿 ≤ 300 字。
- 每页至少一个视觉元素：公式、图示、插图、表格、重点框。
- 一页只讲一个核心点；讲不下就拆页。
- 例题与练习必须与教材出处一致；不确定的内容标注「非教材内容」。
- 讲稿是「家长怎么讲」，不是页面文字的复述：多提问、多引导、给生活例子。

## 布局选择

| 内容 | 推荐 layout |
|---|---|
| 引入/封面 | `cover` |
| 目标清单 | `objectives` |
| 概念定义 + 公式 | `concept` |
| 操作步骤/解题流程 | `steps` |
| 文字与图片对照 | `two-column` |
| 一张大图讲清 | `diagram` |
| 课堂练习 | `quiz` |
| 总结/作业 | `summary` |

## 内容块组合

- 概念页：`text(lead)` + `formula`/`illustration` + `callout(key)`。
- 步骤页：`bullets(ordered)`；每步 ≤ 20 字，讲稿补充细节。
- 图示页：`diagram` + 1–2 句 `text` 或 `callout`。
- 错题页：`mistake` 块 + `callout(warn)` 提醒易错点。
- 小结页：`bullets` + `text(note)`。

## 视觉约束

- 卡通手绘风格由模板保证：粗描边、圆角、贴纸、气泡；不要再描述颜色/字体。
- 插图只写 `kind + params`，不要写坐标；复杂图用 `diagram` 的确定性类型。
- 每页最多 1 张插图；图片比例由模板控制。
