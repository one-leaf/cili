# 学科适配与错因分类

## 学科课件结构

| 学科 | 页面重点 | 建议视觉 |
|---|---|---|
| 数学 | 概念 → 例题（审题/思路/计算/检验）→ 变式 → 练习 | 数轴、分数条、几何图、步骤图 |
| 语文 | 背景 → 字词/句段 → 文本分析 → 表达方法 → 练习 | 文本对照、结构图、表格 |
| 英语 | 词汇/句型 → 语境示例 → 操练 → 小结 | 词汇表、对话气泡、图标行 |
| 物理/化学 | 现象 → 概念/规律 → 实验/装置 → 例题 → 练习 | 装置图、流程图、表格 |
| 生物 | 结构 → 功能 → 过程 → 应用 | 结构示意、流程图 |
| 历史/地理 | 时间线/区域 → 因果/特征 → 材料分析 → 小结 | 时间线、地图示意（用图示参数，不引用外部地图） |
| 道法/思政 | 教材口径 → 案例 → 辨析 → 小结 | 要点卡片、对比表 |

## 家长版讲稿

- 先问「你觉得呢/你是怎么想的」，再给提示，最后才给答案。
- 用生活例子解释抽象概念；一次只推进一个小步骤。
- 易错点用「提醒」语气，不指责。
- 每页结尾留一个可互动的问题或小任务。

## 错因分类（错题模式）

| 类型 | 判定线索 | 常见学科 |
|---|---|---|
| 概念不清 | 定义/性质/边界混淆，选项本身理解错 | 数学、物理、化学、生物 |
| 方法不会 | 知道概念但不知道从哪下手/步骤缺失 | 全学科 |
| 计算失误 | 思路对但算错、符号/单位错 | 数学、物理、化学 |
| 审题偏差 | 漏条件、看错问法、答非所问 | 全学科 |
| 记忆不牢 | 公式/字词/事实记错 | 语文、英语、历史 |
| 表达不规范 | 答案对但格式/语言不规范 | 语文、英语 |
| 操作失误 | 实验/作图/工具使用错误 | 物理、化学、生物、信息技术 |
| 待分类 | 信息不足或多因混合 | 全部 |

规则：已填错因优先；未填则根据题目、作答、正确答案、解析推断并标记 `inferred`；判断不了归「待分类」；每条只取一个主类型。

## 错题模式页面

- 开头：错题分布 + 数据来源/时间范围/推断说明。
- 每类：类型讲解 → 典型错例（原文）→ 正确方法 → 变式练习。
- 结尾：检查清单 + 下一步建议。
- 不编造学生答案；不自动删除或标记「已掌握」。
