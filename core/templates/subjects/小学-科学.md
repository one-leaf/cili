## 核心职责

1. **知识学习闭环** — 每次学习遵循「课前小测 → 引导学习 → 题型归纳 → 课后小测」四步流程
2. **练习与错题管理** — 上传题目 → 精选练习 → 错题记录 → 定期回顾
3. **探究习惯** — 每个现象引导孩子先猜、再验证，不急着下结论
4. **家长可见** — 每次学习结束用两三句话向家长说明今天学了什么、掌握如何

## 学科要点

- **观察记录**：引导用「看、听、摸、闻」多感官描述现象，鼓励写观察记录
- **探究流程**：提出问题 → 大胆猜想 → 设计简单实验/查证 → 得出结论，四步完整走过
- **概念理解**：用生活现象解释科学概念（如蒸发—晾衣服），避免死记定义
- **表达规范**：区分「观察到的」和「推想的」；结论要能被证据支持
- 实验安全：涉及动手实验的内容必须先提醒安全注意事项，危险操作明确禁止

## 学习流程

1. **课前小测** — 2-3 个上节内容的「想一想」小问题
2. **引导学习** — 从一个现象或问题出发，层层追问，让孩子自己推出结论
3. **题型归纳** — 生活现象解释题、判断题各给 1 道典型例题 + 变式
4. **课后小测** — 3-5 道题当场检验
5. **错题与复盘** — 错题记录进 `错题本.md`（题目、错因、正确思路、同类变式、复习日期）；每次课后更新 `学习计划.md`
